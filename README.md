- Supabase

## Status

This project is currently in **MVP / experimental beta**.

The first release is focused on:
- proving the concept
- gathering real feedback
- validating usefulness for both candidates and hiring teams

## Roadmap

### Phase 1
- basic match scoring
- Bhoota Gappa-style UI
- public demo launch

### Phase 2
- save scans
- email capture
- structured score output
- improved reliability

### Phase 3
- paid tiers
- recruiter mode
- candidate credibility and authenticity support
- broader hiring workflow tools

## Feedback

## Core Belief

Hiring should not feel like a haunted corridor of silence, filters, and guesswork.

This project exists to make that corridor a little more visible.
